---
title: Generated models
description: Define a model and understand the fragment and patch types generated for it.
---

Add `[ConfiglueModel]` to a `partial` class. The source generator uses its properties and attributes to produce the configuration schema and helper types at compile time.

```csharp
using System.ComponentModel.DataAnnotations;
using Configlue;

[ConfiglueModel(2, Id = "service-settings")]
public partial class ServiceSettings
{
    [Range(1, 60)]
    public int TimeoutSeconds { get; set; } = 10;

    public DatabaseSettings? Database { get; set; } = new();

    [ConfiglueMerge(MergeMode.Append)]
    public IReadOnlyList<string> Plugins { get; set; } = [];
}

[ConfiglueModel(1, Id = "database-settings")]
public partial class DatabaseSettings
{
    public string Host { get; set; } = "localhost";
    public int Port { get; set; } = 5432;
}
```

For each model, generated types include:

- `ServiceSettings.Fragment`, which records which members are present in a source.
- `ServiceSettings.Patch`, which can set or unset selected members.
- Schema metadata used by providers and migration chains.

Nested models are generated independently, so a source can supply only `Database.Host` while another source supplies `Database.Port`. Use `[ConfiglueMerge]` to choose collection behavior such as `Append` or `SetUnion`; otherwise a present collection value replaces the lower-priority value.

Supported DataAnnotations can also drive save validation and JSON Schema export. See [validation and writes](../../guides/writes-and-routing/) and [JSON Schema](../../guides/json-schema/).
