---
title: Sparse fragments
description: Preserve the difference between missing, null, default, and explicit values.
---

Ordinary configuration objects cannot tell whether `false` came from a file or from a model default. Generated fragments keep that information by storing each member as `Optional<T>`.

```csharp
var fragment = new AppSettings.Fragment
{
    Enabled = Optional<bool>.Present(false),
    Label = Optional<string?>.Present(null),
};
```

Here `Enabled` is explicitly false, `Label` is explicitly null, and every unassigned member is missing. During resolution, a missing member leaves the lower-priority contribution visible. Present default values still override lower layers.

The generated `Patch` type represents edits as set or unset operations. Unsetting a member removes the selected source's contribution; it can reveal a value from a lower-priority source. A normal save computes a semantic diff and changes only the selected source contribution.

Collection merge behavior can be selected with `[ConfiglueMerge]`. `Append` combines collection segments, `SetUnion` removes duplicates, and the default replace behavior uses the highest-priority present collection.
