Configlue is a .NET library for reading, resolving, editing, and persisting typed configuration from independent sources. A source contributes only the fields it owns, so values can be layered without replacing an entire settings object.

## What Configlue provides

- Source-generated model fragments and patches, with semantic merge and diff operations.
- Priority-based resolution across independent sources.
- Separate resource, codec, and source contracts.
- Read-only, writable, and watched sources that can be combined as needed.
- Dependency injection, named profiles, validation, migration, and property-level explanations.
