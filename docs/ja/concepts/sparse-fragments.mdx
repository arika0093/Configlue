---
title: 疎なフラグメント
description: 未設定、null、既定値、明示された値を区別します。
---

通常の設定オブジェクトだけでは、`false` がファイルに書かれていたのか、モデルの既定値なのか判断できません。生成されるフラグメントは各メンバーを `Optional<T>` として保持し、この情報を維持します。

```csharp
var fragment = new AppSettings.Fragment
{
    Enabled = Optional<bool>.Present(false),
    Label = Optional<string?>.Present(null),
};
```

この例では `Enabled` は明示的に false、`Label` は明示的な null で、代入していないメンバーは未設定です。解決時に未設定メンバーは下位ソースの値を残します。メンバーが既定値であっても、存在すれば下位の値を上書きします。

生成された `Patch` 型は設定と解除を操作として表します。メンバーを解除すると、書き込み先ソースの値だけが削除され、下位ソースの値が再び見えることがあります。通常の保存は意味的な差分を求め、選択したソースの寄与だけを変更します。

`[ConfiglueMerge]` でコレクションのマージ方法を選べます。`Append` はコレクションを追加し、`SetUnion` は重複を除きます。既定の置き換え動作では、最も優先度の高い存在するコレクションを使います。
