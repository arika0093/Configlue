---
title: ソースと優先度
description: 独立したソースがひとつのモデルに値を提供する仕組みです。
---

状態ソースは、固定された論理 ID、リーダー、優先度を持ち、任意でライターや変更監視機能を提供します。バックエンドに応じて読み取り専用、書き込み可能、監視可能なソースを組み合わせられます。

ソースは優先度の高い順に読み込まれます。Configlue は疎なフラグメントに存在するメンバーをマージします。高優先度の値が同じメンバーを持つ場合はその値が使われ、欠けている項目は低優先度のソースから補われます。入れ子のモデルもメンバー単位でマージします。

```csharp
var sources = new StateSourceSet<AppSettings.Fragment>([
    new("local", localReader, priority: 100),
    new("defaults", defaultsReader, priority: 0),
]);
```

ローカルファイルで一部の設定だけを上書きし、それ以外は既定値を使う構成ができます。フォールバック条件はソース全体が `NotFound` または `Unavailable` を返したときに次のソースを試すかを決めます。成功したフラグメントのメンバー単位のマージ動作は変えません。

読み取りと書き込み先は別に指定できます。既定ではライターを持つソースのうち最も優先度が高いものに書き込みます。更新先を固定するには `StateWriteRoute.To("local")` を使います。

論理ソース ID と物理リソース ID は異なります。同じファイルやアーカイブの複数のセクション表示は、共有する `ResourceId` を持たせて書き込みを調整できます。
