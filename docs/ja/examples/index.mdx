---
title: サンプル
description: Configlue の代表的な使い方を示す小さなアプリケーションです。
---

リポジトリの [`example/` ディレクトリ](https://github.com/arika0093/Configlue/tree/main/example)に実行できるプロジェクトがあります。コマンドはリポジトリのルートから実行してください。

| サンプル | 内容 | 実行 |
| --- | --- | --- |
| `Example.ConsoleApp` | DI と JSON ファイルリソースを使う生成モデル。 | `dotnet run --project example/Example.ConsoleApp` |
| `Example.SimpleApp` | DI コンテナーを使わないファイル設定。 | `dotnet run --project example/Example.SimpleApp` |
| `Example.ConsoleApp.NativeAot` | ソース生成 JSON メタデータと NativeAOT 向けの投影。 | `dotnet publish example/Example.ConsoleApp.NativeAot --configuration Release --runtime linux-x64 --self-contained true` |
| `Example.ConsoleApp.Yaml` | YAML に保存する生成モデル。 | `dotnet run --project example/Example.ConsoleApp.Yaml` |
| `Example.WorkerService` | Generic Host とバックグラウンドワーカー。 | `dotnet run --project example/Example.WorkerService` |
| `Example.MultiSource` | HTTP ポリシー、明示設定、ローカル、グローバル設定の組み合わせ。 | `dotnet run --project example/Example.MultiSource` |

コンソールの例では `-- --set-name Ada` を付けて名前を更新できます。複数ソースの例は `CONFIGLUE_POLICY_URL` が設定されていれば HTTP ソースを読み、未設定なら JSON ファイルを使います。実行方法は [`example/README.md`](https://github.com/arika0093/Configlue/blob/main/example/README.md) にあります。
