---
title: JSON Schema を出力する
description: 生成されたモデルメタデータからバージョン付き JSON Schema を作成します。
---

`JsonSchemaGenerator` はモデルの `ConfiglueModelSchema` から JSON Schema を出力します。モデルの JSON メタデータを渡してください。トリミングや NativeAOT ではソース生成コンテキストを使います。

```csharp
using System.Text.Json.Serialization;

[JsonSerializable(typeof(AppSettings))]
internal partial class AppJsonContext : JsonSerializerContext { }

var schema = JsonSchemaGenerator.Generate<AppSettings, AppSettings.Fragment>(
    AppJsonContext.Default);
var written = JsonSchemaGenerator.Write<AppSettings, AppSettings.Fragment>(
    "schemas",
    AppJsonContext.Default);
```

対応する DataAnnotations はスキーマ制約に変換されます。スキーマ構造を明示する場合は override 属性や one-of 属性を使います。

生成されたスキーマにはモデル ID とバージョンが含まれます。スキーマが表すのは解決後の値です。保存フラグメントは、各ソースがどのメンバーを提供したかも維持します。
