---
title: 依存性注入
description: DI 対応のソースビルダーで状態ソースを登録します。
---

`AddConfiglueOptions<TModel, TFragment>` は解決済みオプションを `IReadOnlyOptions<TModel>` と `IWritableOptions<TModel>` として登録します。ソース設定コールバックはオプションのシングルトン作成時に呼び出されるため、その中でプロバイダーサービスを解決できます。

```csharp
services.AddSingleton<UserSettingsStore>();
services.AddSingleton<DefaultsStore>();

services.AddConfiglueOptions<AppSettings, AppSettings.Fragment>(
    (provider, sources) =>
    {
        var user = provider.GetRequiredService<UserSettingsStore>();
        var defaults = provider.GetRequiredService<DefaultsStore>();

        sources.Add("user", user, priority: 100);
        sources.Add("defaults", defaults, priority: 0);
    },
    writeRoute: StateWriteRoute.To("user"),
    validateDataAnnotations: true);
```

`sources.Add` はリーダーが実装するライターと監視機能を検出します。別サービスがそれらを提供する場合は、戻り値に `.WithWriter(...)` または `.WithWatcher(...)` を呼びます。検出済み機能を無効にするには `.WithoutWriter()` または `.WithoutWatcher()` を使います。

読み取りには `IReadOnlyOptions<TModel>`、編集には `IWritableOptions<TModel>` を解決します。クラスモデルでは Microsoft の `IOptions<T>`、`IOptionsSnapshot<T>`、`IOptionsMonitor<T>` アダプターも登録されます。同期プロパティの読み取りは Configlue の同期読み取りを行うため、非同期フローでは Configlue の非同期メソッドを使ってください。
