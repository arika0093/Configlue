import { Steps } from '@astrojs/starlight/components';

環境変数を追加すると、初めて読み取り専用の上書きが登場します。これによって、読み取り時の優先順位と書き込み先が別の規則であることを確認できます。

<Steps>

1. ### Environment レイヤーを追加する

   ```csharp
   await using var context = ConfiglueApp.CreateContext(config =>
       config.UseCommonSources(sources =>
       {
           sources.WithUserGlobal("TutorialApp");
           sources.WithLocal();
           sources.WithEnvironment("EXAMPLE");
           sources.Add<AppSettings>();
       }));
   ```

2. ### 入れ子の値を環境変数で指定する

   プロパティ階層は `__` で区切ります。

   ```sh
   export EXAMPLE__SERVER__PORT=9000
   ```

   Environment はファイル層より優先順位が高いため、有効な `Server.Port` は `9000` になります。

3. ### 保存前に上書き状態を調べる

   ```csharp
   var state = context.GetState<AppSettings>();
   var details = await state.GetDetailsAsync();

   Console.WriteLine(details.Server.Port.Value);
   Console.WriteLine(details.Server.Port.IsEditable);
   Console.WriteLine(details.Server.Port.Source?.Locator);
   ```

   Local が書き込み可能でも、読み取り専用の Environment が同じ項目を上書きしている間は、通常の保存経路から有効値を変更できない場合があります。

4. ### 競合を明示的に扱う

   上書きされた項目へ別の値を保存しようとすると、`StateConflictException` が発生することがあります。ファイルへの書き込みが成功すれば有効値も変わると仮定せず、環境変数を外す、別の項目だけを保存する、ソース構成を変更するといった方法を選びます。

</Steps>
