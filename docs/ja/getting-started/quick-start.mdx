## 必要な環境

Configlue は .NET 10 を対象にしています。メインパッケージと JSON プロバイダーを追加します。

```sh
dotnet add package Configlue
dotnet add package Configlue.Provider.Json
```

`Configlue` パッケージにはランタイムとソースジェネレーターが含まれます。プロバイダーは別パッケージなので、アプリが使う形式だけを追加します。

## モデルを定義する

`partial` クラスに `ConfiglueModel` を付けます。ソースジェネレーターが疎な `Fragment` 型と `Patch` 型を生成します。

```csharp
using Configlue;

[ConfiglueModel(1, Id = "app-settings")]
public partial class AppSettings
{
    public string Theme { get; set; } = "System";
    public string? ServiceUrl { get; set; }
}
```

引数の数値はスキーマバージョンです。モデルの `Id` は固定し、保存形式の変更にマイグレーションが必要な場合はバージョンを上げてください。

## JSON ファイルを登録する

`FileResource` はファイルの読み取り、原子的な書き込み、リビジョン、バックアップ、変更通知を扱います。`JsonStateCodec` は生成フラグメントを JSON に変換します。`SerializedStateSource` は両者を組み合わせ、リソースの書き込みと監視機能を自動で検出します。

```csharp
using Configlue;
using Configlue.Provider.Json;
using Microsoft.Extensions.DependencyInjection;

var services = new ServiceCollection();
services.AddSingleton(new FileResource("appsettings.user.json"));
services.AddConfiglueOptions<AppSettings, AppSettings.Fragment>(
    (provider, sources) =>
    {
        var file = provider.GetRequiredService<FileResource>();
        var source = SerializedStateSource.FromResource<AppSettings.Fragment>(
            "user-settings",
            file,
            new JsonStateCodec(),
            priority: 100);
        sources.Add(source);
    },
    writeRoute: StateWriteRoute.To("user-settings"));

using var provider = services.BuildServiceProvider();
var options = provider.GetRequiredService<IReadOnlyOptions<AppSettings>>();
var writable = provider.GetRequiredService<IWritableOptions<AppSettings>>();

var settings = await options.GetValueAsync();
await writable.SaveAsync(current => current.Theme = "Dark");
```

初回の保存より前に読み込む場合は、フラグメントをファイルに用意します。

```json
{
  "$configlue": { "id": "app-settings", "version": 1 },
  "$value": { "Theme": "System", "ServiceUrl": "https://api.example.test" }
}
```

Configlue はソースに存在する値を解決します。利用できるソースがない場合、モデルの既定値だけで成功扱いにはなりません。初期フラグメントを用意するか、読み取り結果の `NotFound` を処理してください。

次に[ソースの優先度とマージ](/ja/concepts/sources-and-priority/)と[疎なフラグメント](/ja/concepts/sparse-fragments/)を確認してください。
