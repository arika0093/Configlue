このページでは、Configlue を最小構成で動かします。扱うのは1つのモデルと1つの JSON ファイルだけです。複数ソースや DI はチュートリアルの後半で追加します。

<Steps>

1. ### ファイルベースアプリを作る

   次の内容を `app.cs` として保存します。.NET 10 のファイルベースアプリでは、ソースファイルから NuGet パッケージを指定できます。

   ```csharp
   #:package Configlue@*

   using Configlue;
   using Configlue.Provider.Json;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.Add<AppSettings>(model =>
           model.UseJsonFile("settings.json")));

   var state = context.GetState<AppSettings>();

   var current = await state.GetValueAsync();
   Console.WriteLine($"Hello, {current.Name}! Run #{current.RunCount}");

   await state.SaveAsync(patch =>
   {
       patch.Name = "Ada";
       patch.RunCount = current.RunCount + 1;
   });

   [ConfiglueModel("example.quick-start", Version = 1)]
   public partial class AppSettings
   {
       public string Name { get; set; } = "World";
       public int RunCount { get; set; }
   }
   ```

2. ### 実行する

   ```sh
   dotnet run app.cs
   ```

   最初の読み取りでは設定ファイルが存在しないため、モデルの初期値が使われます。その後の `SaveAsync` は、Patch で変更した項目だけを `settings.json` に保存します。

3. ### もう一度実行する

   2回目は `settings.json` に保存した値を読み取り、`RunCount` をさらに1増やします。

</Steps>
