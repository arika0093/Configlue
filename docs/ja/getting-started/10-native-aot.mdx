---
title: "NativeAOT で配布する"
description: ソース生成メタデータを用いて NativeAOT やトリミング環境で安全に動作させます。
---

import { Steps, Tabs, TabItem } from '@astrojs/starlight/components';

単一ファイル配布や起動速度向上のために NativeAOT を利用する場合、リフレクションに依存したシリアライザーは動作しません。
Configlue は、`System.Text.Json` のソース生成コンテキスト（`JsonSerializerContext`）を渡すことで NativeAOT に対応します。

<Steps>

1. ### ソース生成メタデータを定義する

   `JsonSerializerContext` を作成し、設定モデルとそのフラグメントを登録します。

   ```csharp
   using System.Text.Json.Serialization;
   using Configlue.Provider.Json;

   [JsonSerializable(typeof(AppSettings))]
   [JsonSerializable(typeof(AppSettings.Fragment))]
   internal partial class AppJsonContext : JsonSerializerContext
   {
   }
   ```

2. ### 生成した JSON コンテキストをファイル層に渡す

   ソース生成した `JsonSerializerContext` を各ファイル層の `.Json(...)` に渡します。
   これにより、リフレクションなしで安全に JSON の読み書きが行われます。

   <Tabs syncKey="di">
   <TabItem label="DI なし">

   ```csharp
   using Configlue;
   using Configlue.Source.Presets;

   await using var context = ConfiglueApp.CreateContext(conf =>
       conf.UseCommonSources(sources =>
       {
           sources.WithGlobal("TutorialApp").Json(AppJsonContext.Default);
           sources.WithLocal().Json(AppJsonContext.Default);
           sources.Add<AppSettings>();
       })
   );
   ```

   </TabItem>
   <TabItem label="DI あり">

   ```csharp
   using Configlue;
   using Configlue.Source.Presets;

   builder.Services.AddConfiglue(conf =>
       conf.UseCommonSources(sources =>
       {
           sources.WithGlobal("TutorialApp").Json(AppJsonContext.Default);
           sources.WithLocal().Json(AppJsonContext.Default);
           sources.Add<AppSettings>();
       })
   );
   ```

   </TabItem>
   </Tabs>

   > [!NOTE]
   > YAML プロバイダー（`Configlue.Provider.Yaml`）を利用する場合は、生成されたフラグメントスキーマとシリアライザーオプションを渡すことでトリミングに対応します。XML プロバイダーは `XmlSerializer` を内部で使用するため、現時点では完全な AOT トリミングには制約があります。

   YAML シリアライザーコンテキスト、`JsonTypeInfo` ベースのコーデックコンストラクター、XML のトリミング制約については [NativeAOT](../advanced/native-aot.md) を参照してください。

3. ### サンプルプロジェクトで動作を検証する

   リポジトリに含まれる NativeAOT サンプルを発行してテストできます。

   ```bash
   dotnet publish example/Example.ConsoleApp.NativeAot --configuration Release
   ```

</Steps>

## 次に読む
