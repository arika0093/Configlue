# STEP 5: 環境変数に対応する

コンテナ環境（Docker）や CI/CD パイプラインでは、ファイルではなく環境変数を用いて設定値を上書きしたい場面が多くあります。
環境変数は**読み取り専用**のソースです。
Configlue の標準構成である CommonSource を利用すると、オプションを 1 つ指定するだけで環境変数レイヤーを導入できます。

<Steps>

1. ### CommonSource で環境変数を有効化する

   `CommonSourceOptions` の `EnvironmentPrefix` に接頭辞（プレフィックス）を指定します。

   <Tabs syncKey="di">
   <TabItem label="DI なし">

   ```csharp
   using Configlue;
   using Configlue.Source.Common;

   await using var context = ConfiglueApp.CreateContext(conf =>
   {
       conf.Add<AppSettings>(model =>
       {
           model.UseCommonSources(new CommonSourceOptions
           {
               ApplicationId = "TutorialApp",
               GlobalFileName = "settings.json",
               EnvironmentPrefix = "EXAMPLE", // 接頭辞 EXAMPLE を指定
           });
       });
   });
   ```

   </TabItem>
   <TabItem label="DI あり">

   ```csharp
   using Configlue;
   using Configlue.Source.Common;

   builder.Services.AddConfiglue(conf =>
   {
       conf.Add<AppSettings>(model =>
       {
           model.UseCommonSources(new CommonSourceOptions
           {
               ApplicationId = "TutorialApp",
               GlobalFileName = "settings.json",
               EnvironmentPrefix = "EXAMPLE",
           });
       });
   });
   ```

   </TabItem>
   </Tabs>

2. ### 環境変数による値の上書きルール

   環境変数の名前は、二重アンダースコア（`__`）でプロパティの階層を区切ります。
   大文字と小文字は区別されません。

   たとえば `Server.Port` を上書きしたい場合、以下の環境変数を設定します。

   ```bash
   export EXAMPLE__SERVER__PORT=9000
   ```

   CommonSource において、環境変数レイヤーはファイルレイヤーよりも高い優先度を持ちます。
   そのため、ローカルファイルに別の値が記述されていても、環境変数の値が優先して採用されます。

3. ### 読み取り専用値があるときの保存と競合

   環境変数は読み取り専用であるため、アプリケーションから書き換えることはできません。
   では、`EXAMPLE__SERVER__PORT` で値が覆われている状態で `SaveAsync` を呼び出すとどうなるでしょうか。

   ```csharp
   // EXAMPLE__SERVER__PORT が設定されている場合、この保存は失敗します
   await options.SaveAsync(patch => patch.Server!.Port = 9000);
   ```

   この保存は、**`StateConflictException`（競合例外）** を投げて中断されます。
   上位の読み取り専用ソースによって隠されてしまう変更を無言でファイルに書き込むと、実行結果とファイルの内容の乖離（不整合）が発生するためです。

   安全に対処するには、以下のいずれかを選択します。

   - 実行環境の環境変数を解除してから保存する。
   - 環境変数で上書きされていない他のプロパティのみを保存する。
   - `GetDetailsAsync` を使って、あらかじめ値の出どころを確認してから保存を行う。

4. ### 出どころの確認

   ```csharp
   var details = await options.GetDetailsAsync();
   Console.WriteLine(details.Server.Port);
   ```

   出力結果には、現在の実効値だけでなく、値を提供しているソース名（環境変数レイヤーかファイルレイヤーか）が表示されます。

</Steps>
