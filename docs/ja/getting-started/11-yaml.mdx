---
title: "YAML と JSON を併用する"
description: YAML を主としつつ既存の JSON も読み込み、複数形式を併用します。
---

import { Steps, Tabs, TabItem } from '@astrojs/starlight/components';

このガイドは、レイヤーの基本を理解した後に複数のファイル形式を組み合わせる例です。YAML を主な保存先にし、既存の JSON ファイルを読み取り専用のフォールバックとして残します。

フォーマットが異なっていても、Configlue のソースとレイヤーの基本ルールは共通です。

<Steps>

1. ### YAML プロバイダーパッケージを追加する

   ```bash
   dotnet add package Configlue.Provider.Yaml
   ```

2. ### YAML と JSON を組み合わせる

   プリセットでは対象のファイル層に `.Yaml()` を指定します。拡張子から Provider が自動選択されることはありません。
   YAML（主）と JSON（従）の優先度を直接構成する場合は、以下のように `model.Sources(...)` を利用できます。

   <Tabs syncKey="di">
   <TabItem label="DI なし">

   ```csharp
   using Configlue;
   using Configlue.Provider.Json;
   using Configlue.Provider.Yaml;

   conf.Add<AppSettings>(model =>
   {
       model.Sources(sources =>
       {
           // 主：YAML ファイル（優先度高・書き込み先）
           sources.FromYamlFile(new()
           {
               Id = "settings-yaml",
               Path = "settings.yaml",
               Priority = 200,
           });

           // 従：既存の JSON ファイル（優先度低・読み取り専用）
           sources.FromJsonFile(new()
           {
               Id = "settings-json",
               Path = "settings.json",
               Priority = 100,
               ReadOnly = true, // 明示的に読み取り専用に設定
           });
       });

       model.WriteRoute = StateWriteRoute.To("settings-yaml");
   });
   ```

   </TabItem>
   <TabItem label="DI あり">

   ```csharp
   using Configlue;
   using Configlue.Provider.Json;
   using Configlue.Provider.Yaml;

   builder.Services.AddConfiglue(conf =>
   {
       conf.Add<AppSettings>(model =>
       {
           model.Sources(sources =>
           {
               sources.FromYamlFile(new()
               {
                   Id = "settings-yaml",
                   Path = "settings.yaml",
                   Priority = 200,
               });

               sources.FromJsonFile(new()
               {
                   Id = "settings-json",
                   Path = "settings.json",
                   Priority = 100,
                   ReadOnly = true,
               });
           });

           model.WriteRoute = StateWriteRoute.To("settings-yaml");
       });
   });
   ```

   </TabItem>
   </Tabs>

3. ### 読み取りと保存の挙動

   - **読み取り**: 両方のファイルが合成されます。YAML に存在するプロパティは YAML が優先され、YAML に存在しないプロパティは JSON の値が維持されます。
   - **保存**: `WriteRoute` で指定した `settings-yaml` にのみ保存されます。既存の JSON ファイルは変更されません。

</Steps>
