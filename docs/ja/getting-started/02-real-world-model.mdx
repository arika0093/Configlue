import { Steps } from '@astrojs/starlight/components';

設定モデルには、通常の入れ子クラスやコレクションを含められます。モデルが大きくなっても、`GetValueAsync` と `SaveAsync` を使う基本の流れは変わりません。

<Steps>

1. ### 入れ子の設定を追加する

   ```csharp
   [ConfiglueModel("tutorial.settings", Version = 1)]
   public partial class AppSettings
   {
       public string Name { get; set; } = "ExampleApp";
       public ServerSettings Server { get; set; } = new();
       public List<string> EnabledFeatures { get; set; } = [];
   }

   public class ServerSettings
   {
       public string Host { get; set; } = "localhost";
       public int Port { get; set; } = 8080;
   }
   ```

   ルートモデルの一部として使う入れ子クラスには、`[ConfiglueModel]` を付ける必要はありません。

2. ### 入れ子の項目だけを保存する

   ```csharp
   await options.SaveAsync(patch =>
   {
       patch.Server.Port = 9000;
   });
   ```

   この保存では `Server.Port` だけがそのソースの寄与になります。モデルのほかの初期値まで保存状態へ変換されるわけではありません。

3. ### コレクションを置き換える

   ```csharp
   await options.SaveAsync(patch =>
   {
       patch.EnabledFeatures = ["audit-log", "metrics"];
   });
   ```

   設定画面のように多数の項目を可変モデルとして編集したい場合は、後で説明する edit session を使います。更新対象が決まっている処理では Patch の方が単純です。

</Steps>
