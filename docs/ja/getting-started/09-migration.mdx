---
title: "スキーマと保存場所を移行する"
description: 互換性のない変更時にモデルの版（Version）を上げ、旧モデルからの移行を定義します。
---

import { Steps, Tabs, TabItem } from '@astrojs/starlight/components';

プロパティの名称変更や型の変更など、互換性のないモデル改変が発生したとき、Configlue ではモデルの **Version** をインクリメントし、旧モデルからの移行ロジックを宣言します。
これにより、ユーザーの手元にある既存の設定ファイルを破棄することなく、安全に読み替えが可能です。

<Steps>

1. ### モデルの版を上げる

   新しいモデルを Version 2 として定義し、以前のモデル（Version 1）を別名クラスとして保持します。
   後続のステップで利用するプロパティ（`Server`, `Database`）も維持しておきます。

   ```csharp
   using Configlue;

   // Version 2（新しいモデル）
   [ConfiglueModel("tutorial.settings", Version = 2)]
   public partial class AppSettings
   {
       public string DisplayName { get; set; } = "ExampleApp"; // Name から改名
       public ServerSettings Server { get; set; } = new();
       public DatabaseSettings Database { get; set; } = new();
   }

   // Version 1（過去のモデル）
   [ConfiglueModel("tutorial.settings", Version = 1)]
   public partial class AppSettingsV1
   {
       public string Name { get; set; } = "ExampleApp";
       public ServerSettings Server { get; set; } = new();
       public DatabaseSettings Database { get; set; } = new();
   }
   ```

2. ### 移行ロジックを実装する

   `[ConfigluePreviousVersion]` 属性を付与し、旧モデルから新モデルへの変換メソッド `Migrate` を記述します。

   ```csharp
   [ConfigluePreviousVersion(typeof(AppSettingsV1))]
   public partial class AppSettings
   {
       public AppSettings Migrate(AppSettingsV1 source) => new()
       {
           DisplayName = source.Name, // 旧 Name の値を新 DisplayName へマッピング
           Server = source.Server,
           Database = source.Database,
       };
   }
   ```

   同名かつ型の互換性があるプロパティは自動的に引き継がれるため、改名や値変換が必要な項目だけを記述します。

3. ### 保存場所の移行（Storage Migration）

   スキーマの移行だけでなく、「古い設定ファイルから新しいファイルへの移行」や「ソースの退役」を行いたい場合は、`MigrateSourceAsync` API を使用します。

   <Tabs syncKey="di">
   <TabItem label="DI なし">

   ```csharp
   var sources = context.GetSources<AppSettings>();
   var result = await sources.MigrateSourceAsync("legacy-settings", "settings");
   Console.WriteLine($"{result.SourceId} から {result.TargetId} へ移行が完了しました。");
   ```

   </TabItem>
   <TabItem label="DI あり">

   ```csharp
   public sealed class SettingsMigrator(IConfiglueSources<AppSettings> state)
   {
       public async Task MigrateAsync()
       {
           var result = await state.MigrateSourceAsync("legacy-settings", "settings");
           Console.WriteLine($"{result.SourceId} から {result.TargetId} へ移行が完了しました。");
       }
   }
   ```

   </TabItem>
   </Tabs>

</Steps>
