---
title: "専用の設定ソースを暗号化する"
description: ユーザー名とパスワードを専用の JSON ソースに保存し、AES-GCM で暗号化します。
---

import { Steps } from '@astrojs/starlight/components';

ユーザー名やパスワードのように、通常の設定ファイルとは分けて保存したい情報があります。
ここではモデルにユーザー情報を追加し、OS 標準のユーザー設定ディレクトリにある `secrets.bin` へ JSON 形式で保存します。JSON を Codec でシリアライズした後、`AesGcmStateByteTransformer` で暗号化する構成です。

> [!CAUTION]
> 暗号化キーは暗号化対象ファイルとは別の安全な場所で管理してください。この例では説明を簡単にするため環境変数から Base64 の 32 バイト鍵を読みます。鍵は `openssl rand -base64 32` などで一度だけ生成し、毎回同じ鍵を使ってください。本番では OS の資格情報ストアやシークレット管理サービスを使ってください。鍵を紛失すると `secrets.bin` を復号できません。

<Steps>

1. ### モデルにユーザー情報を追加する

   STEP 2 の `AppSettings` に、ユーザー名とパスワードを追加します。

   ```csharp
   public string? Username { get; set; }
   public string? Password { get; set; }
   ```

2. ### AES トランスフォーマーパッケージを追加する

   ```bash
   dotnet add package Configlue.Transformer.AES
   ```

3. ### `secrets.bin` を専用の暗号化 JSON ソースとして登録する

   JSON ファイルソースに AES トランスフォーマーを設定します。リソースのパスは `ConfiglueStandardPaths.GetStandardSaveDirectory` から取得するため、OS 標準のユーザー設定ディレクトリが使われます。

   ```csharp
   using System.Security.Cryptography;
   using Configlue;
   using Configlue.Provider.Json;
   using Configlue.Source.Presets;
   using Configlue.Transformer.AES;

   var encodedKey = Environment.GetEnvironmentVariable("TUTORIAL_AES_KEY")
       ?? throw new InvalidOperationException("Set TUTORIAL_AES_KEY to a stable Base64-encoded AES key.");
   var key = Convert.FromBase64String(encodedKey);
   using var aes = new AesGcmStateByteTransformer(key);
   CryptographicOperations.ZeroMemory(key);

   var secretsKey = SourceKey<AppSettings>.Named("secrets");
   var secretsPath = Path.Combine(
       ConfiglueStandardPaths.GetStandardSaveDirectory("TutorialApp"),
       "secrets.bin");

   await using var context = ConfiglueApp.CreateContext(conf =>
       conf.UseCommonSources(sources =>
       {
           sources.WithUserGlobal("TutorialApp");
           sources.WithLocal();
           sources.WithCustom(
               CommonSourceLayer.Explicit,
               sourceSet => sourceSet.FromJsonFile(new JsonFileSourceOptions
               {
                   Id = "secrets",
                   Path = secretsPath,
                   Transformers = [aes],
               }));
           sources.Add<AppSettings>();
       })
   );

   var sourceAdmin = context.GetSources<AppSettings>();
   ```

   AES トランスフォーマーはファイルリソースと JSON Codec の間に位置するため、リソース上の `secrets.bin` は暗号文です。復号した内容は通常の Configlue JSON ドキュメントになります。

4. ### 資格情報を専用ソースへ保存する

   `sourceAdmin.Source(secretsKey)` を使うと、変更先を `secrets` ソースに限定できます。通常の `state.SaveAsync` は CommonSource の既定保存先に書き込むため、資格情報の保存にはこのハンドルを使います。

   ```csharp
   await sourceAdmin.Source(secretsKey).SaveAsync(patch =>
   {
       patch.Username = "ada";
       patch.Password = "example-password";
   });
   ```

   復号後の JSON は概ね次の形です。これはディスク上の `secrets.bin` の内容ではありません。

   ```json
   {
     "$version": 1,
     "Username": "ada",
     "Password": "example-password"
   }
   ```

</Steps>
