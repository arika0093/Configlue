---
title: "STEP 1: 1つのファイルを読み書きする"
description: 1つのモデルと1つの JSON ファイルから始め、疎な保存を確認する。
---

import { Steps } from '@astrojs/starlight/components';

チュートリアルでは通常のコンソールプロジェクトを使い、新しい概念を一つずつ追加します。最初のステップでは、設定の入力元を1つの JSON ファイルだけにします。

<Steps>

1. ### 設定モデルを定義する

   ```csharp
   using Configlue;

   [ConfiglueModel("tutorial.settings", Version = 1)]
   public partial class AppSettings
   {
       public string Name { get; set; } = "World";
       public int RunCount { get; set; }
   }
   ```

   `[ConfiglueModel]` と `partial` が必要なのは、Configlue が管理するルートモデルです。

2. ### JSON ファイルを1つ登録する

   ```csharp
   using Configlue;
   using Configlue.Provider.Json;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.Add<AppSettings>(model =>
           model.UseJsonFile("settings.json")));

   var options = context.GetOptions<AppSettings>();
   ```

   `UseJsonFile` が作成したファイルリソースと watcher は context が所有し、context の破棄時に停止します。

3. ### 現在の値を読む

   ```csharp
   var current = await options.GetValueAsync();
   Console.WriteLine($"Hello, {current.Name}! Run #{current.RunCount}");
   ```

   `settings.json` が存在しない場合でも、モデルの初期値から有効な設定値を組み立てられます。

4. ### 変更した項目だけを保存する

   ```csharp
   await options.SaveAsync(patch =>
   {
       patch.Name = "Ada";
       patch.RunCount = current.RunCount + 1;
   });
   ```

   `SaveAsync` は疎な Patch を保存します。モデルに初期値があるという理由だけで、変更していない項目までファイルへ書き出すことはありません。

</Steps>
