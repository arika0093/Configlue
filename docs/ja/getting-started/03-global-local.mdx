import { Steps } from '@astrojs/starlight/components';

前のステップまではソースが1つでした。ここでは、ユーザー単位の Global ファイルを下位の設定として置き、Local ファイルに存在する項目だけを上書きする構成へ進みます。

<Steps>

1. ### 単一ファイルを CommonSource に置き換える

   ```csharp
   using Configlue;
   using Configlue.Source.Presets;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.UseCommonSources(sources =>
       {
           sources.WithGlobal("TutorialApp");
           sources.WithLocal();
           sources.Add<AppSettings>();
       }));

   var options = context.GetOptions<AppSettings>();
   ```

   `Global` は OS 標準のユーザー設定ディレクトリを使います。`Local` はカレントディレクトリの `settings.json` を使い、読み取り時には Global より高い優先順位を持ちます。

2. ### 合成された値を読む

   Local に存在する項目は、同じ項目の Global の値を上書きします。Local にない項目は Global から補われ、どちらのファイルにもなければモデルの初期値が使われます。

3. ### 値の出所を確認する

   ```csharp
   var details = await options.GetDetailsAsync();

   Console.WriteLine(details.Server.Port.Value);
   Console.WriteLine(details.Server.Port.Source?.DisplayName);
   ```

   `GetDetailsAsync` は、同じ解決処理から有効値と各ソースの寄与をまとめたスナップショットを返します。

4. ### 必要なときだけ保存先を明示する

   この構成で通常の `SaveAsync` が使う保存先は Local です。Global に意図して保存する場合は、context からソース管理用の機能を取得します。

   ```csharp
   var sources = context.GetSources<AppSettings>();

   await sources.Source(CommonSource.Global).SaveAsync(patch =>
   {
       patch.Name = "Shared default";
   });
   ```

   ここで変更するのは Global の寄与です。Local など、より優先順位の高いソースに同じ項目があれば、有効値はそちらのままです。

</Steps>
