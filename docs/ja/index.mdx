Configlue は、独立したソースから型付き設定を読み込み、解決し、編集して保存するソースジェネレーター中心の .NET ライブラリです。各ソースは自分が持つ項目だけを提供するため、設定オブジェクト全体を置き換えずに値を重ねられます。

## 何ができるか

<CardGrid stagger>
  <Card title="独立したソースを重ねる" icon="layers">
    JSON・YAML・XML・環境変数・コマンドライン・HTTP リソースを優先度でマージします。各ソースは自分の項目だけを持ちます。
  </Card>
  <Card title="疎に編集する" icon="pencil">
    1つのプロパティだけ保存、編集セッション、複数ソースへの振り分けに対応します。触っていない項目は保持されます。
  </Card>
  <Card title="定義を使い回す" icon="puzzle">
    同じモデル・ソース定義が DI あり/なしの両方で動き、`IOptions<T>` アダプターも付きます。
  </Card>
  <Card title="値の出どころを説明" icon="magnifier">
    `Database.Host` がどこから来たかを、優先度順の各ソース寄与とともに確認できます。
  </Card>
  <Card title="プロファイルと動的オプション" icon="user">
    永続化される名前付きプロファイルと、実行時に増減できるドキュメント単位のオプションに対応します。
  </Card>
  <Card title="安全に移行する" icon="arrow-right">
    生成コードによるモデル版管理、検証つきソース間コピー、既存 `Configuration.Writable` ファイルの取り込みに対応します。
  </Card>
  <Card title="検証とスキーマ" icon="approve-check">
    DataAnnotations または独自バリデーター、版つき JSON Schema 出力に対応します。
  </Card>
  <Card title="NativeAOT 対応" icon="rocket">
    ソース生成されたシリアル化メタデータでトリミング安全に動作し、NativeAOT サンプルも同梱しています。
  </Card>
</CardGrid>
