Configlue は、独立したソースから型付き設定を読み込み、解決し、編集して保存する .NET ライブラリです。各ソースは自分が持つ項目だけを提供するため、設定オブジェクト全体を置き換えずに値を重ねられます。

## Configlue の機能

- ソース生成によるモデルフラグメントとパッチ。意味的なマージと差分に対応します。
- 優先度に基づく複数ソースの解決。
- リソース、コーデック、ソースを分離した契約。
- 読み取り専用、書き込み可能、変更監視を組み合わせられるソース。
- 依存性注入、名前付きプロファイル、検証、マイグレーション、プロパティ単位の説明。
