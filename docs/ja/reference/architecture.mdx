---
title: アーキテクチャ
description: Configlue の境界と現在の実装状況です。
---

Configlue は論理スキーマと物理ストレージ構成を分離します。ソースは論理スナップショットを提供し、リソースは物理エンドポイントを表し、コーデックはバイト列を変換し、生成フラグメントはメンバーの有無を記録します。解決、マイグレーション、投影、書き込み計画はフラグメントを扱い、アプリケーションコードは通常のモデルを編集します。

複数のソースがひとつのモデルの部分木に値を提供でき、複数のビューが同じリソースを共有できます。セクションリソースと ZIP エントリーリソースはこの ID を維持し、互換性のある更新をまとめます。異なる物理リソースへの書き込みは原子的ではありません。

現在、生成される疎なフラグメント、優先度付き解決、JSON/XML/YAML コーデック、各形式のセクションリソース、ファイルと ZIP リソース、環境変数ソース、ソースのマイグレーションと投影、JSON Schema 出力、DI プロファイル、永続プロファイルカタログ、Microsoft Options アダプター、変更通知、リビジョン確認付き書き込みを実装しています。

詳しくは[アーキテクチャ設計ノート](/ja/reference/design-notes/)を参照してください。現状は設計基盤の実装段階であり、プロバイダー別の変更監視方針など、今後の作業が残っています。
