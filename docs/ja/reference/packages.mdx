---
title: パッケージとプロジェクト
description: Configlue の機能ごとに対応する NuGet パッケージを確認します。
---

| パッケージ | プロジェクト | 役割 |
| --- | --- | --- |
| `Configlue` | `src/Configlue` | ランタイム登録とソースジェネレーターを含む利用者向けパッケージ。 |
| `Configlue.Abstraction` | `src/Configlue.Abstraction` | モデル、状態、リソース、コーデック、オプションの契約。 |
| `Configlue.Core` | `src/Configlue.Core` | ソース解決、オプションランタイム、シリアライズ合成、ファイルリソース。 |
| `Configlue.Generator` | `src/Configlue.Generator` | 疎なフラグメントとパッチをコンパイル時に生成。 |
| `Configlue.Testing` | `src/Configlue.Testing` | アプリケーションテスト用のメモリ内リソースとストア。 |
| `Configlue.Provider.Json` | `src/Configlue.Provider.Json` | JSON コーデック、セクション、JSON Schema 出力。 |
| `Configlue.Provider.Xml` | `src/Configlue.Provider.Xml` | XML コーデックとセクションリソース。 |
| `Configlue.Provider.Yaml` | `src/Configlue.Provider.Yaml` | YAML コーデックとセクションリソース。 |
| `Configlue.Source.Environment` | `src/Configlue.Source.Environment` | プロセス環境変数から作る読み取り専用ソース。 |
| `Configlue.Resource.Zip` | `src/Configlue.Resource.Zip` | ZIP アーカイブのエントリーを扱うリソース。 |
| `Configlue.Resource.Http` | `src/Configlue.Resource.Http` | ETag リビジョンとポーリングに対応する HTTP リソース。 |

パッケージ名とバージョンの正本は各プロジェクトファイルです。必要なプロバイダーパッケージを個別に追加してください。
