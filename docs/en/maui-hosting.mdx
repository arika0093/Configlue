---
title: MAUI hosting
---

Install `Configlue.Hosting.Maui`. It uses MAUI Essentials contracts; the consuming
MAUI application's target framework selects the native Essentials implementation.
Core and the shared ComponentModel adapters remain independent of MAUI.

## Host paths and UI dispatch

Call `builder.UseMaui()` while configuring a context. An optional `IFileSystem`
argument supports dependency injection and tests.

- `UserGlobal` is `FileSystem.Current.AppDataDirectory`, with no second application
  identifier appended.
- `BackupRoot` is the persistent `Configlue/Backups` subdirectory of that root.
- `HostGlobal` and `Local` are unsupported and fail explicitly through the standard
  directory API.

Use `new MauiConfiglueDispatcher()` as the dispatcher for
`ConfiglueStateReader<T>` or `ConfiglueStateEditor<T>`. It calls MAUI's
`MainThread.IsMainThread` and `BeginInvokeOnMainThread`. Native host initialization
must already be complete. On Windows, MAUI needs a registered native window to
find the main-thread queue from a background thread; the regular MAUI application
startup performs that registration.

## Small-secret resources

`new SecureStorageResource(secureStorage, "application-owned-key")` accepts an
injected `ISecureStorage`, for example `SecureStorage.Default`. It composes with
the ordinary serialized-source pipeline: a codec serializes a Fragment to bytes,
the resource base64-encodes those bytes, and the native store protects the string.
Use distinct keys for distinct logical documents or subjects.

The default raw payload limit is 1 KiB and can be changed with
`maximumContentBytes`. Base64 and native encryption increase the stored size.
This limit does not guarantee that every native store can accept that size;
platform failures are preserved for application recovery. Use this resource for
small credentials, tokens, API keys, or key material. Ordinary configuration
documents should use regular file/provider resources.

A missing native value maps to `NotFound`; an existing empty payload is successful.
Invalid base64 or a payload exceeding the configured limit reports `InvalidPayload`.
The codec is responsible for schema metadata inside its payload. This resource
does not add Preferences, a watcher, batch transactions, or plaintext backups.

### Revisions and concurrency

Revisions are SHA-256 fingerprints of the stored base64 string. Conditional writes
check the observed revision or absence before setting the entry. Resources sharing
the **same `ISecureStorage` instance and key** serialize their conditional writes
within the process. Inject/reuse that instance for cooperating writers.

The native stores provide no cross-process CAS. Direct native writes, different
storage wrappers, and other processes can race this check-and-set. These revisions
describe content, not a write counter; writing the same content preserves its
revision. They do not imply a distributed transaction or change history.

Cancellation is checked before a native operation and before committing a write.
Native `SetAsync` itself has no cancellation token. Once it commits, the resource
returns the committed revision even if cancellation was requested during that call.

### Native platform behavior

MAUI documents [SecureStorage platform behavior](https://learn.microsoft.com/en-us/dotnet/maui/platform-integration/storage/secure-storage):

- Android restores can leave encrypted entries unusable when the original encryption
  keys are unavailable; follow MAUI's backup exclusion and recovery guidance.
- Apple Keychain entries can outlive an app uninstall, and iCloud Keychain can sync
  entries across devices depending on the platform's behavior and settings.
- Native storage size and access restrictions vary. Treat exceptions as a platform
  recovery decision; the resource does not silently fall back to plaintext storage.

Portable tests use injected filesystem and secure-storage services and cover binary
encoding, conditional writes across instances, payload limits, cancellation, and
generated Fragment/JSON pipeline composition. Windows smoke tests exercise native
MAUI filesystem, SecureStorage, and main-thread dispatch with a registered hidden
WinUI window. Android/iOS/macOS device validation is still required for their native
storage and lifecycle behavior; portable tests do not prove those platform paths.
