# Standalone SparseFragments

`SparseFragments` provides presence-aware model algebra without Configlue sources,
routing, ownership, codecs, or runtime services. Decorate a partial model with
`[SparseFragmentModel]` to generate its nested `Fragment`, `FragmentBuilder`, and
`Patch` types. Supported undecorated structural children receive these types too.

## Typed mutations

```csharp
var patch = new Settings.Patch();
patch.Label = FragmentOperation<string?>.Set(null); // present null
patch.RetryCount = FragmentOperation<int>.Unset;    // remove contribution
patch.Nested.Port = 9000;                          // change one child member
var updated = fragment.Apply(patch);
```

An unassigned patch member is unchanged. Direct assignment of a value creates a
Set operation. Nested patches support `Set(model)`, `SetNull()`, and `Unset()`.
Member operations are applied after a nested whole-contribution operation; they
can create a child contribution when the child was missing or null. Neither
`Apply` nor builder edits modify the original fragment.

`fragment.ToPatch()` converts present members to Set operations and leaves missing
members unchanged. `fragment.ToBuilder()` copies presence into a mutable builder.
Assign `Optional<T>.Missing` to remove a builder member, and call `Build()` to
create a fragment. Child fragments have their own `ToBuilder()` methods.

Whole-contribution operations are available through
`ISparseModelPatch<TModel, TModel.Fragment>`, including when model members are named
`Set`, `SetNull`, or `Unset`. Its `Apply(Optional<Fragment?>)` method preserves all
three contribution states: missing, present null, and present fragment.
`Fragment.Apply(patch)` returns a fragment and throws if a whole-contribution
operation produces missing or null; use the interface method for those states.

## Persistence contract

SparseFragments is model algebra only and defines no serialization format.
Reflection serialization of generated fragments or `Optional<T>` is not a
supported persistence contract. An application serializer must explicitly omit
missing members and preserve present null and present default values if it needs
to persist sparse contributions. No Configlue codec dependency is required.

## Deep cloning

Generated `DeepClone()` recursively clones generated models, supported structural
objects, and recognized collections, including collection elements, dictionary
keys, and values. It preserves shared references and cycles for the supported
mutable reference graph and preserves the comparers of supported dictionaries and
sets.

Unknown mutable reference types, including unknown types nested in a recognized
collection, produce `SPF008`. Use a structural type with a supported public
construction shape, or mark a property `[SparseCloneReferenceSafe]` only when its
referenced object is safe for callers to share. This explicit policy is also
required when a member uses `SparseMerge(MergeMode.Replace)`; replacement merge
behavior does not make a shallow clone independent.
