# STEP 5: Environment variables

In containers (Docker) or CI/CD pipelines, settings are often injected via environment variables rather than files.
Environment variables act as a **read-only** source.
With Configlue's CommonSource, enabling this layer requires only a single property.

<Steps>

1. ### Enable environment variables in CommonSource

   Supply an `EnvironmentPrefix` in `CommonSourceOptions`:

   <Tabs syncKey="di">
   <TabItem label="Without DI">

   ```csharp
   using Configlue;
   using Configlue.Source.Common;

   await using var context = ConfiglueApp.CreateContext(conf =>
   {
       conf.Add<AppSettings>(model =>
       {
           model.UseCommonSources(new CommonSourceOptions
           {
               ApplicationId = "TutorialApp",
               GlobalFileName = "settings.json",
               EnvironmentPrefix = "EXAMPLE", // Prefix for environment variables
           });
       });
   });
   ```

   </TabItem>
   <TabItem label="With DI">

   ```csharp
   using Configlue;
   using Configlue.Source.Common;

   builder.Services.AddConfiglue(conf =>
   {
       conf.Add<AppSettings>(model =>
       {
           model.UseCommonSources(new CommonSourceOptions
           {
               ApplicationId = "TutorialApp",
               GlobalFileName = "settings.json",
               EnvironmentPrefix = "EXAMPLE",
           });
       });
   });
   ```

   </TabItem>
   </Tabs>

2. ### Property naming and priority

   Environment variables separate property paths with double underscores (`__`) and are case-insensitive:

   ```bash
   export EXAMPLE__SERVER__PORT=9000
   ```

   The environment layer has higher priority than local and global files, overriding whatever values exist in those files.

3. ### Saving with read-only overrides (Conflict Detection)

   Because environment variables cannot be written by the application, attempting to save a value that is currently overridden by an environment variable throws a **`StateConflictException`**:

   ```csharp
   // Throws StateConflictException if EXAMPLE__SERVER__PORT is currently set
   await options.SaveAsync(patch => patch.Server!.Port = 9000);
   ```

   This prevents silent discrepancies between file content and the runtime configuration.
   To handle this safely:
   - Unset the environment variable before persisting.
   - Save only unaffected fields.
   - Check value provenance with `GetDetailsAsync` beforehand.

</Steps>
