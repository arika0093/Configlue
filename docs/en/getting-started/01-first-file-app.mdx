title: "STEP 1: Read and save one file"
description: Start with one model, one JSON file, and sparse saves.

import { Steps } from '@astrojs/starlight/components';

The tutorial uses a normal console project and adds one concept at a time. This first step keeps the source topology to one JSON file.

<Steps>

1. ### Define the settings model

   ```csharp
   using Configlue;

   [ConfiglueModel("tutorial.settings", Version = 1)]
   public partial class AppSettings
   {
       public string Name { get; set; } = "World";
       public int RunCount { get; set; }
   }
   ```

   Only the root Configlue model needs `[ConfiglueModel]` and `partial`.

2. ### Register one JSON file

   ```csharp
   using Configlue;
   using Configlue.Provider.Json;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.Add<AppSettings>(model =>
           model.UseJsonFile("settings.json")));

   var state = context.GetState<AppSettings>();
   ```

   The context owns the file resource created by `UseJsonFile` and disposes its watcher with the state runtime.

3. ### Read the effective value

   ```csharp
   var current = await state.GetValueAsync();
   Console.WriteLine($"Hello, {current.Name}! Run #{current.RunCount}");
   ```

   If `settings.json` does not exist, the model defaults still produce a usable value.

4. ### Save only the changed members

   ```csharp
   await state.SaveAsync(patch =>
   {
       patch.Name = "Ada";
       patch.RunCount = current.RunCount + 1;
   });
   ```

   Configlue saves a sparse patch. Members that were not assigned are not copied into the file merely because they have defaults in the model.

</Steps>
