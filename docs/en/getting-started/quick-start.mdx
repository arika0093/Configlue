This page is for trying Configlue with the smallest useful example. It uses one model and one JSON file; layering and dependency injection come later.

<Steps>

1. ### Create a file-based app

   Save the following as `app.cs`. .NET 10 file-based apps can restore the package directly from the source file.

   ```csharp
   #:package Configlue@*

   using Configlue;
   using Configlue.Provider.Json;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.Add<AppSettings>(model =>
           model.UseJsonFile("settings.json")));

   var options = context.GetOptions<AppSettings>();

   var current = await options.GetValueAsync();
   Console.WriteLine($"Hello, {current.Name}! Run #{current.RunCount}");

   await options.SaveAsync(patch =>
   {
       patch.Name = "Ada";
       patch.RunCount = current.RunCount + 1;
   });

   [ConfiglueModel("example.quick-start", Version = 1)]
   public partial class AppSettings
   {
       public string Name { get; set; } = "World";
       public int RunCount { get; set; }
   }
   ```

2. ### Run it

   ```sh
   dotnet run app.cs
   ```

   On the first read, no settings file exists, so the model defaults are used. `SaveAsync` then writes only the members changed by the patch to `settings.json`.

3. ### Run it again

   The second run reads the values written to `settings.json` and increments `RunCount` again.

</Steps>
