## Requirements

Configlue targets .NET 10. Add the main package and the JSON provider to your application:

```sh
dotnet add package Configlue
dotnet add package Configlue.Provider.Json
```

The `Configlue` package includes the runtime and source generator. Providers are separate packages, so install only the formats or resource types your application uses.

The repository also has a [console application example](https://github.com/arika0093/Configlue/tree/main/example/Example.ConsoleApp).

## Define a model

Mark a partial class with `ConfiglueModel`. The source generator adds a sparse `Fragment` type and a `Patch` type for it.

```csharp
using Configlue;

[ConfiglueModel(1, Id = "app-settings")]
public partial class AppSettings
{
    public string Theme { get; set; } = "System";
    public string? ServiceUrl { get; set; }
}
```

The numeric argument is the schema version. Keep the `Id` stable for a model and increase the version when you make a storage change that needs migration.

## Register a JSON file

`FileResource` handles file reads, atomic writes, revisions, backups, and change notifications. `JsonStateCodec` encodes generated fragments. `SerializedStateSource` connects the resource and codec and detects the resource's writer and watcher capabilities.

```csharp
using Configlue;
using Configlue.Provider.Json;
using Microsoft.Extensions.DependencyInjection;

var services = new ServiceCollection();
services.AddSingleton(new FileResource("appsettings.user.json"));
services.AddConfiglueOptions<AppSettings, AppSettings.Fragment>(
    (provider, sources) =>
    {
        var file = provider.GetRequiredService<FileResource>();
        var source = SerializedStateSource.FromResource<AppSettings.Fragment>(
            "user-settings",
            file,
            new JsonStateCodec(),
            priority: 100);
        sources.Add(source);
    },
    writeRoute: StateWriteRoute.To("user-settings"));

using var provider = services.BuildServiceProvider();
var options = provider.GetRequiredService<IReadOnlyOptions<AppSettings>>();
var writable = provider.GetRequiredService<IWritableOptions<AppSettings>>();

var settings = await options.GetValueAsync();
await writable.SaveAsync(current => current.Theme = "Dark");
```

Seed the file with one fragment if the application needs to read it before its first save:

```json
{
  "$configlue": { "id": "app-settings", "version": 1 },
  "$value": { "Theme": "System", "ServiceUrl": "https://api.example.test" }
}
```

Configlue resolves only values present in its sources. A new file with no usable source will not silently become a fully populated model; seed an initial fragment or handle the `NotFound` read status.
