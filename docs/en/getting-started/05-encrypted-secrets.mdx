# STEP 5: Encrypt user credentials

Some values, such as usernames and passwords, should be stored separately from ordinary settings.
This step adds those values to the model and writes them as JSON to `secrets.bin` in the platform-standard per-user configuration directory. The JSON codec serializes the state first, then `AesGcmStateByteTransformer` encrypts the bytes.

> [!CAUTION]
> Keep the encryption key in a secure location separate from the encrypted file. This example reads a Base64-encoded 32-byte key from an environment variable for simplicity. Generate the key once (for example, with `openssl rand -base64 32`) and reuse the same key on each run. Use an OS credential store or secrets manager in production. Losing the key means `secrets.bin` cannot be decrypted.

<Steps>

1. ### Add user credentials to the model

   Add these properties to `AppSettings` from STEP 2:

   ```csharp
   public string? Username { get; set; }
   public string? Password { get; set; }
   ```

2. ### Add the AES transformer package

   ```bash
   dotnet add package Configlue.Transformer.AES
   ```

3. ### Register `secrets.bin` as a dedicated JSON source

   Place the AES transformer between `FileResource` and the JSON codec. The path uses `ConfiglueStandardPaths.GetStandardSaveDirectory`, so it resolves to the platform-standard per-user configuration directory.

   ```csharp
   using System.Security.Cryptography;
   using Configlue;
   using Configlue.Provider.Json;
   using Configlue.Source.Presets;
   using Configlue.Transformer.AES;

   var encodedKey = Environment.GetEnvironmentVariable("TUTORIAL_AES_KEY")
       ?? throw new InvalidOperationException("Set TUTORIAL_AES_KEY to a stable Base64-encoded AES key.");
   var key = Convert.FromBase64String(encodedKey);
   using var aes = new AesGcmStateByteTransformer(key);
   CryptographicOperations.ZeroMemory(key);

   var secretsKey = SourceKey<AppSettings>.FromId("secrets");
   var secretsPath = Path.Combine(
       ConfiglueStandardPaths.GetStandardSaveDirectory("TutorialApp"),
       "secrets.bin");
   using var secretsResource = new FileResource(secretsPath);

   await using var context = ConfiglueApp.CreateContext(conf =>
       conf.UseCommonSources(sources =>
       {
           sources.WithGlobal("TutorialApp");
           sources.WithLocal();
           var secrets = SerializedStateSource.FromResource<AppSettings.Fragment>(
               "secrets",
               secretsResource,
               new JsonStateCodec<AppSettings.Fragment>(),
               priority: 300,
               transformers: [aes]);
           sources.WithCustom(
               CommonSourceLayer.Explicit,
               sourceSet => sourceSet.Add(secretsKey, secrets))
               .Priority(300);
           sources.Add<AppSettings>();
       })
   );

   var options = (IConfiglueOptions<AppSettings>)context.GetOptions<AppSettings>();
   ```

   Because the AES transformer follows the JSON codec on writes, `secrets.bin` contains ciphertext. Its decrypted content is an ordinary Configlue JSON document.

4. ### Save credentials to the dedicated source

   `options.Source(secretsKey)` targets only the `secrets` source. Ordinary `options.SaveAsync` uses CommonSource's default destination, so use this source handle for credentials.

   ```csharp
   await options.Source(secretsKey).SaveAsync(patch =>
   {
       patch.Username = "ada";
       patch.Password = "example-password";
   });
   ```

   The decrypted JSON looks roughly like this. This is not the content stored on disk in `secrets.bin`.

   ```json
   {
     "$version": 1,
     "Username": "ada",
     "Password": "example-password"
   }
   ```

</Steps>
