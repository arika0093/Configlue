As applications evolve, property renames and structural changes inevitably occur.
In Configlue, breaking changes are handled by incrementing the model's **Version** and implementing a migration from the previous model shape, ensuring older files are converted rather than broken.

<Steps>

1. ### Increment the model version

   Define the new shape as Version 2 and retain the previous model under an alias class (e.g. `AppSettingsV1`).
   Retain nested properties (`Server`, `Database`) used in subsequent steps:

   ```csharp
   using Configlue;

   // Version 2 (new shape)
   [ConfiglueModel("tutorial.settings", Version = 2)]
   public partial class AppSettings
   {
       public string DisplayName { get; set; } = "ExampleApp"; // Renamed from Name
       public ServerSettings Server { get; set; } = new();
       public DatabaseSettings Database { get; set; } = new();
   }

   // Version 1 (previous shape)
   [ConfiglueModel("tutorial.settings", Version = 1)]
   public partial class AppSettingsV1
   {
       public string Name { get; set; } = "ExampleApp";
       public ServerSettings Server { get; set; } = new();
       public DatabaseSettings Database { get; set; } = new();
   }
   ```

2. ### Write the migration method

   Annotate the new model with `[ConfigluePreviousVersion]` and supply a `Migrate` method:

   ```csharp
   [ConfigluePreviousVersion(typeof(AppSettingsV1))]
   public partial class AppSettings
   {
       public AppSettings Migrate(AppSettingsV1 source) => new()
       {
           DisplayName = source.Name, // Map old Name to new DisplayName
           Server = source.Server,
           Database = source.Database,
       };
   }
   ```

   Same-name and type-compatible properties copy automatically; only renamed or transformed properties require explicit assignments.

3. ### Storage migration (Moving between sources)

   Beyond shape changes, moving settings between physical storage locations or retiring legacy sources is performed using `MigrateSourceAsync`:

   <Tabs syncKey="di">
   <TabItem label="Without DI">

   ```csharp
   var sources = context.GetSources<AppSettings>();
   var result = await sources.MigrateSourceAsync("legacy-settings", "settings");
   Console.WriteLine($"Copied from {result.SourceId} to {result.TargetId}.");
   ```

   </TabItem>
   <TabItem label="With DI">

   ```csharp
   public sealed class SettingsMigrator(IConfiglueSources<AppSettings> options)
   {
       public async Task MigrateAsync()
       {
           var result = await options.MigrateSourceAsync("legacy-settings", "settings");
           Console.WriteLine($"Copied from {result.SourceId} to {result.TargetId}.");
       }
   }
   ```

   </TabItem>
   </Tabs>

</Steps>
