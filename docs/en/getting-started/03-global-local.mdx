---
title: "STEP 3: Combine global and local settings"
description: Add a second source and inspect which source supplies each value.
---

import { Steps } from '@astrojs/starlight/components';

The previous steps had one source. This step introduces layering: a lower-priority per-user file provides shared values, and a local file overrides only the members it contains.

<Steps>

1. ### Replace the single file with CommonSource

   ```csharp
   using Configlue;
   using Configlue.Source.Presets;

   await using var context = ConfiglueApp.CreateContext(config =>
       config.UseCommonSources(sources =>
       {
           sources.WithGlobal("TutorialApp");
           sources.WithLocal();
           sources.Add<AppSettings>();
       }));

   var state = context.GetState<AppSettings>();
   ```

   `Global` uses the platform-standard per-user configuration directory. `Local` uses `settings.json` in the current working directory and has higher read priority.

2. ### Read the merged value

   A member present in Local overrides the same member from Global. A member missing from Local can still come from Global or, if neither file contributes it, from the model defaults.

3. ### Inspect where a value came from

   ```csharp
   var details = await state.GetDetailsAsync();

   Console.WriteLine(details.Server.Port.Value);
   Console.WriteLine(details.Server.Port.Source?.DisplayName);
   ```

   `GetDetailsAsync` returns one consistent resolution snapshot, including the effective value and its source contributions.

4. ### Choose a source explicitly when necessary

   Ordinary `SaveAsync` uses the preset's default writable layer, which is Local in this configuration. To write the lower Global layer intentionally, get the source-administration capability from the context.

   ```csharp
   var sources = context.GetSources<AppSettings>();

   await sources.Source(CommonSource.Global).SaveAsync(patch =>
   {
       patch.Name = "Shared default";
   });
   ```

   An explicit source write changes that source's contribution; a higher-priority source can still shadow it.

</Steps>
