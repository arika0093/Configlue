Configlue is a source-generator-first .NET library for reading, resolving, editing, and persisting typed configuration from independent sources. Each source contributes only the fields it owns, so values can be layered without replacing an entire settings object.

## What can it do?

<CardGrid stagger>
  <Card title="Layer independent sources" icon="layers">
    Merge JSON, YAML, XML, environment variables, command-line options, and HTTP resources by priority. Each source owns only its fields.
  </Card>
  <Card title="Edit sparsely" icon="pencil">
    Save a single property, open an edit session, or route one edit across several sources. Untouched members are preserved.
  </Card>
  <Card title="Reuse one definition" icon="puzzle">
    The same model and source definitions work with and without dependency injection, plus `IOptions<T>` adapters.
  </Card>
  <Card title="Explain every value" icon="magnifier">
    Ask where `Database.Host` came from and see each source contribution from highest to lowest priority.
  </Card>
  <Card title="Profiles and dynamic options" icon="user">
    Persist named profiles with an active-profile catalog, or add per-document options at runtime.
  </Card>
  <Card title="Migrate safely" icon="arrow-right">
    Version models with generated migrations, copy sources with verification, and adopt existing `Configuration.Writable` files.
  </Card>
  <Card title="Validate and schema" icon="approve-check">
    DataAnnotations or custom validators, plus versioned JSON Schema export for editors and CI.
  </Card>
  <Card title="NativeAOT ready" icon="rocket">
    Source-generated serialization metadata keeps trimming-safe apps working, with a NativeAOT sample included.
  </Card>
</CardGrid>
