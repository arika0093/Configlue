---
title: Built-in providers
description: Choose the resource and codec packages that match your configuration storage.
---

Provider packages are independent of the `Configlue` runtime package. Pair a codec with a resource using `SerializedStateSource.FromResource<TFragment>`.

## JSON

Install `Configlue.Provider.Json` and use `JsonStateCodec`. `JsonSectionResource` exposes a nested path such as `App:Settings` or `App__Settings` and preserves sibling values when it writes.

```csharp
var section = new JsonSectionResource(file, "App:Settings");
var source = SerializedStateSource.FromResource<AppSettings.Fragment>(
    "app-settings", section, new JsonStateCodec(), priority: 50);
```

The package also contains JSON Schema export. See the [schema guide](../json-schema/).

## XML and YAML

Install `Configlue.Provider.Xml` or `Configlue.Provider.Yaml` and pair `XmlStateCodec` or `YamlStateCodec` with the corresponding section resource. `XmlSectionResource` accepts a nested element path; `YamlSectionResource` accepts a mapping path. Both preserve sibling sections and check the revision of the whole underlying resource.

## Environment variables

Install `Configlue.Source.Environment` and create a read-only source with `EnvironmentStateSource.FromEnvironment<TModel, TModel.Fragment>("environment", "APP")`. Names such as `APP__DATABASE__HOST` map to nested model members; matching is case-insensitive. The built-in parser handles common scalar types, and an optional parser delegate can handle application-specific values. Process environment variables do not provide a change watcher.

## ZIP entries

Install `Configlue.Resource.Zip` to use `ZipEntryResource` as a resource view over one archive entry. The archive's identity and revision are retained, untouched entries remain intact, and disjoint entry updates can share one batched archive write.

## HTTP resources

Install `Configlue.Resource.Http` to read bytes from `{root}/get`, write bytes to `{root}/update`, and poll for changes. Compose `HttpResourceReader` with a codec using `SerializedStateSource.FromResource<TFragment>`; call `CreateWriter()` and pass it as `writer:` only when the endpoint accepts updates. Configure authentication on the caller-owned `HttpClient`.

The resource uses ETags for revisions and conditional writes. A 404 becomes `NotFound`; timeouts, transport failures, 408, 429, and server errors become `Unavailable`; authorization and other client errors are surfaced. See the [HTTP resource protocol](../reference/http-resource-protocol.md) for the wire contract and schema headers.

For custom storage, implement `IResourceReader` and optionally `IResourceWriter`, `IResourceBatchWriter`, and `IStateWatcher`; then compose it with a codec or create a `StateSource<TFragment>` directly.
