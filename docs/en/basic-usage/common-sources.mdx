The **CommonSource** (`UseCommonSources`) feature is the recommended foundation for application configuration in Configlue.
It provides standard layer helpers; only the layers declared in the scope are enabled.

## Why CommonSource as the Default?

Production applications rarely store all settings in a single file:
- Shipped machine-wide or user-wide defaults.
- Local overrides for development or specific workspaces.
- Dynamic environment variable injections in containers and CI/CD.
- Ad-hoc configuration files selected at startup.

`UseCommonSources` provides predictable, fixed precedence for the layers you select.

## Layer Precedence Order

The fixed order runs from lowest to highest priority:

| Layer | Condition | Location / Source | Writes |
| --- | --- | --- | :---: |
| **Global** | `WithGlobal` | OS-standard per-user configuration folder | Writable |
| **Local** | `WithLocal` | Current directory (`settings.json`) | Writable |
| **Explicit** | `WithExplicit` | Caller-supplied file path | Writable |
| **Environment** | `WithEnvironment` | Process environment variables | Read-only |
| **Arguments** | `WithCommandLine` | Command-line parse result | Read-only |
| **HTTP** | `WithHttpPolicy` | Remote JSON policy | Read-only |

The preset assigns source identities and priorities internally (0, 100, 200, 300, 400, and 500). Ordinary `SaveAsync` targets the highest-priority configured file layer; `DefaultWriteLayer` can select another configured file. All configured file layers remain available through semantic selectors.

Provider selection on a preset file layer is explicit: `.Json()` is built in, while `.Yaml()` and `.Xml()` require the `Configlue.Source.Presets.Yaml` and `Configlue.Source.Presets.Xml` adapter packages. The `Configlue.Source.CommandLine` package adds `WithCommandLine`.

## Basic Usage

To apply one preset to multiple models, use the scoped builder from `Configlue.Source.Presets`. Only declared sources are enabled, and precedence is fixed: Global < Local < Explicit < Environment < Arguments < HTTP.

```csharp
using Configlue;
using Configlue.Source.Presets;
using System.Text.Json;

await using var context = ConfiglueApp.CreateContext(conf =>
    conf.UseCommonSources(sources =>
{
    sources.WithGlobal("ExampleApp", filename: "settings.yaml")
        .Yaml()
        .FileResourceOptions(new FileResourceOptions { CreateBackup = false });
    sources.WithLocal().Json(new JsonSerializerOptions());
    sources.WithEnvironment("EXAMPLE");
    sources.Add<AppSettings>();
    })
);
```

Use `WithCustom(CommonSourceLayer.Global, ...)` to insert a custom source between built-in layers. Provider serializer/resource settings and the CommandLine mapping API remain available through their provider-specific APIs.

Only explicitly declared layers are enabled. The default write target is the highest-priority configured file layer; use `DefaultWriteLayer` when you want another configured file to receive ordinary writes:

```csharp
using Configlue;
using Configlue.Source.Presets;

await using var context = ConfiglueApp.CreateContext(conf =>
    conf.UseCommonSources(sources =>
    {
        sources.WithGlobal("ExampleApp", filename: "appsettings.json");
        sources.WithLocal();
        sources.WithExplicit(userSpecifiedPath);
        sources.WithEnvironment("EXAMPLE");
        sources.DefaultWriteLayer(CommonSourceLayer.Local);
        sources.Add<AppSettings>();
    })
);
```

For a DI registration, call the same `conf.UseCommonSources(...)` method inside `AddConfiglue`. A file layer can reuse the regular provider APIs, for example `sources.WithGlobal("ExampleApp").Yaml()` or `.FileResourceOptions(...)`.

## Explicit Writes with Semantic Selectors

While `SaveAsync` writes to the default writable layer (typically Local), you can explicitly target a specific layer using type-safe selectors:

```csharp
var sourceAdmin = context.GetSources<AppSettings>();

// Persist to user-wide Global configuration
await sourceAdmin.Source(CommonSource.Global).SaveAsync(patch =>
{
    patch.Theme = "Dark";
});

// Persist to project-level Local configuration
await sourceAdmin.Source(CommonSource.Local).SaveAsync(patch =>
{
    patch.Port = 8080;
});
```

## Extension Patterns

The preset can be extended with provider-specific sources:

### Pattern 1: Command-line overrides

Add `Configlue.Source.CommandLine` to seamlessly integrate `System.CommandLine` parse results:

```csharp
using Configlue.Source.CommandLine;

conf.UseCommonSources(sources =>
{
    sources.WithGlobal("ExampleApp");
    sources.WithLocal();
    sources.WithEnvironment("EXAMPLE");
    sources.WithCommandLine(parseResult, mappings =>
    {
        mappings.Map(portOption, "Server.Port");
        mappings.Map(verboseOption, "Verbose");
    });
    sources.Add<AppSettings>();
});
```

### Pattern 2: Remote policies and additional custom sources

Declare an HTTP policy source directly in the preset scope:

```csharp
conf.UseCommonSources(sources =>
{
    sources.WithGlobal("ExampleApp");
    sources.WithLocal();
    sources.WithHttpPolicy(
        "https://policy.example.internal/api/config",
        httpClient,
        id: "remote-policy");
    sources.Add<AppSettings>();
});
```
